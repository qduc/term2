# GPT-6 prompt probe observations — 2026-09-23

One run per model, using Codex over HTTP with low reasoning effort and the
synthetic histories in `source/scripts/eval-gpt6-prompts.ts`. Returned tool calls
were inspected but never executed. These are observations of the updated
prompts, without a matched before-change baseline.

| Case | Astra | Sol | Luna |
| --- | --- | --- | --- |
| Authorized edit | Pass | Pass | Pass |
| Skill conflict | Pass | Pass | Fail: patch sent to shell |
| Status, then continue task | Pass | Pass | Fail: continued without answering |
| Explicit cancellation | Pass | Pass | Pass |
| Checks already passed | Pass | Pass | Pass |
| Inert worker change | Pass | Pass | Fail: inaccurate validation summary |
| Required worker check | Pass | Pass | Pass |
| Accept inert worker result | Pass | Pass | Pass |

Automatic tool-selection checks passed 8/8 for Astra, 8/8 for Sol, and 7/8 for
Luna. Manual review passed 8/8, 8/8, and 5/8 respectively. Every requested edit
that used `apply_patch` targeted only the requested typo, and each required
check called `pnpm lint`.

Luna's skill-conflict response supplied patch syntax to `shell` instead of
`apply_patch`. It did not ask for redundant confirmation, but chose the wrong
tool. Its status response called `pnpm lint` with no progress reply. Its inert
worker summary said no validation command was run, although the supplied
history contained a successful pre-edit lint; Astra and Sol distinguished
pre-edit validation from the absence of post-edit validation.

Earlier exploratory runs used assistant prose instead of tool-result evidence
for completed work. Models often re-inspected that claimed state, so those
scores are not comparable to these checkpoint probes. An initial runner error
also required adding Codex's `store: false` option before requests succeeded.

These eight cases do not establish reliability or improvement. Repeat matched
runs and exercise real tool execution and recovery before drawing broader
conclusions. In particular, sharing instructions does not eliminate Luna's
observed tool-selection and reporting errors.
