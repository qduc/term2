## Install

Use Node.js 24 or newer.

```bash title="Install"
npm install --global @qduc/term2
term2 --version
```

On Linux, sandboxed shell commands also need `bubblewrap`, `socat`, and `ripgrep`.
See [installation](/term2/getting-started/installation/) for platform details.

Authenticate with [a supported provider](/term2/providers/), then run
`term2 --model` in your project. Select a model from that provider
and enter a prompt.

[Follow the first-run guide →](/term2/getting-started/first-run/)

## Providers

OpenAI, ChatGPT/Codex, Grok, and OpenRouter are built in. Add direct Anthropic,
Gemini, or local endpoints through `/providers`.

Hosted providers receive the context and tool results included in each request.
Their billing and account limits apply.

[Provider setup](/term2/providers/) · [SSH setup](/term2/remote/ssh/)

## Shell commands and file edits

By default, term2 prompts before running shell commands in an interactive
session. Commands run in a sandbox. Edits within the local workspace can apply
without a prompt. See [approvals](/term2/safety/approvals/) for details.

## Releases and source code

Check `term2 --version` for your installation and
